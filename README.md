# Сенс

Щоденна українська гра на близькість значень. Є секретний іменник; кожна спроба отримує ранг за косинусною схожістю векторів слів. Ранг 1 — це відповідь. Менший ранг означає ближче значення.

Інтерфейс лише українською. Окремої англійської версії немає.

## Запуск

```bash
npm install
npm run dev
```

Гра відкриється на [http://127.0.0.1:43127/sens/daily](http://127.0.0.1:43127/sens/daily).

Опублікована версія: [https://fominvo.github.io/sens/](https://fominvo.github.io/sens/). Збірка для GitHub Pages використовує Vite `base: '/sens/'`, тож маршрути, `404.html` і файли в `data/` відкриваються під цим підшляхом. Workflow `.github/workflows/pages.yml` запускає `npm ci && npm run build` і викладає `dist` через `actions/deploy-pages`.

```bash
npm test
npm run build
npm run preview
```

`dist/` — статичний сайт з префіксом `/sens/`. Маршрути `/daily`, `/previous`, `/practice` і `/day/YYYY-MM-DD` збираються відносно цього префікса. Збірка копіює `index.html` у `404.html`: GitHub Pages віддає цей файл для прямого заходу на `/sens/daily`, а скрипти й дані лишаються за абсолютними шляхами `/sens/assets/…` і `/sens/data/…`.

## Як грати

- Щодня опівночі за місцевим часом з’являється новий іменник. Епоха календаря — 1 вересня 2025.
- Введіть слово. Можна будь-яку форму: «яблука» стане «яблуко».
- Список упорядковано від найближчого рангу. Смужка зелена приблизно до 300, жовта до 1500, далі червона.
- У меню є підказка (слово на півдорозі до відповіді) і «Здатися».
- Попередні ігри — календар минулих днів. Тренування — випадкове слово, воно не чіпає щоденну серію.
- Статистика лежить у `localStorage` у цьому браузері.
- «Поділитися» копіює текст без емодзі і без відповіді.

Поле приймає різні апострофи (`'`, `’`, `ʼ`) і літеру `ґ` (для пошуку вона збігається з `г`). Якщо ввімкнена латинська розкладка, слово на кшталт `rsn` читається як «кіт».

## Дані

У `public/data` уже зібраний словник, тож гра запускається без завантаження моделей:

| Файл | Зміст |
| --- | --- |
| `manifest.json` | епоха, кількість пазлів і розмір словника |
| `vocab.json` | леми в початковій формі |
| `forms.bin` | відмінки й інші форми → індекс леми |
| `ranks/N.bin` | ранг кожного слова словника для пазла `N` |

Формат рангів: `SEN1`, далі `uint16` розміру словника і індексу секретного слова, далі `uint16` рангів. Форми: `FRM1`, `uint32` кількість, далі пари `uint16` індекс, `uint8` довжина, UTF-8 ключ. Числа little-endian. Ключі вже без апострофа і з `ґ`, зведеним до `г`.

Поточна збірка: близько 16 тисяч іменників і понад 365 секретних слів (файл `pipeline/secrets_order.txt`, один пазл на рядок).

### Звідки слова і вектори

Повні вектори не входять до репозиторію. Скрипт читає їх потоком і лишає лише підмножину для словника гри: вектор самої леми або, якщо її немає в файлі, середнє векторів відмінених форм.

- **fastText `cc.uk.300`** — українські вектори Common Crawl і Вікіпедії, Facebook AI Research, [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Файл: <https://dl.fbaipublicfiles.com/fasttext/vectors-crawl/cc.uk.300.vec.gz>. Опис: <https://fasttext.cc/docs/en/crawl-vectors.html>. Таблиці рангів — похідна робота і теж доступні на умовах CC BY-SA 3.0.
- **UberText 2.0**, частотний словник лем (lang-uk): <https://lang.org.ua/en/ubertext/>, файл `ubertext_freq.csv.xz`. З нього беруться лише злічені частоти іменників, не тексти корпусу.
- **pymorphy3** і словники **pymorphy3-dicts-uk** потрібні лише під час збірки, щоб перевірити лему й частину мови. Дані словника (CC BY-SA) у репозиторій не копіюються.

Російські словники, сервіси й ресурси на `.ru` не використовуються. Леми з літерами `ы`, `э`, `ъ`, `ё` відкидаються. Власні назви прибираються, коли в UberText у них переважає тег PROPN або pymorphy бачить лише ім’я, прізвище чи топонім. Лайка і образи є в `pipeline/blocklist_uk.txt` і не потрапляють ні в словник, ні в підказки.

### Перебудувати дані

Потрібен Python 3.11+ і файл частот:

```bash
pip install -r pipeline/requirements.txt
curl -L -o /tmp/sens-cache/ubertext_freq.csv.xz \
  https://lang.org.ua/static/downloads/ubertext2.0/dicts/ubertext_freq.csv.xz
xz -dkf /tmp/sens-cache/ubertext_freq.csv.xz
python3 pipeline/build_data.py --freq /tmp/sens-cache/ubertext_freq.csv
```

Перший запуск викачує близько 1,2 ГБ `cc.uk.300.vec.gz`, лишає кеш векторів у `pipeline/.cache/` (його не комітять) і перезаписує `public/data`. Наступні запуски беруть вектори з кешу.

Перевірка сусідів для кількох слів пишеться в `pipeline/sanity_report.txt`.

### Додати секретні слова

1. Допишіть рядок `категорія<TAB>лема` у кінець `pipeline/secrets_uk.txt`. Лема має бути іменником у початковій формі, який уже є у словнику після фільтрів.
2. Запустіть `python3 pipeline/build_data.py` **без** `--rebuild-order`.

Нові слова дописуються в кінець `pipeline/secrets_order.txt`. Номер рядка — це номер пазла від 1 вересня 2025. Не переставляйте вже опубліковані рядки, інакше зміняться минулі дні. `--rebuild-order` навмисно перезбирає весь календар.
